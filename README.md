# Pulse — 社内AIの熱量SNS

従業員がAIの学び・事例・失敗・チャレンジを共有する、**社内専用**のインタラクティブ・プロトタイプ。  
コーポレートなイントラ感を捨て、**ブライトでハイエナジーなライトテーマ**（暖白・サンリットクリーム / 電光ライム / ホットピンク / シアン）で、仕事に使える Gen-Z ソーシャルアプリとして再設計しています。ナイトライフの闇ではなく、フェス／キャンパスの明るい熱量。

バックエンドなし（モックデータ + ローカル state）。

## コンセプト

> 今日の実験が、チームの脈になる。

社内でしか成立しない機能を前面に出し、「失敗を晒せる」「すぐ試せる」「部署で競える」「誰が今どのAIを触ってるか分かる」を一本のプロダクト体験にまとめました。

## ユニーク機能（社内専用）

1. **失敗ブース** — タイムリミット付き匿名懺悔。カウントダウン後に消滅 or REVEAL の空気感。通常フィードとは別画面。
2. **試したチェーン** — ヒント投稿の「コピーして試す」→「試した」一行結果が投稿の下にチェーン表示。
3. **部署対抗チャレンジ** — 週次の部署スコアボード（営業 vs エンジニアなど）。投稿・試したでポイント加算、応援も可。
4. **24h Tips (Stories)** — 画面上部のエフェメラル・ストーリーレール。タップでフルスクリーン寄りのオーバーレイ。
5. **いま触ってる** — Cursor / Claude / ChatGPT など、誰がどのAIツールを使っているかのソフトプレゼンス。
6. **社内ツール棚** — ライセンス済みツール一覧 + 「この人に聞ける」エキスパート。
7. **コアフィード** — フィルター: 学び / 事例 / 質問 / 失敗 / チャレンジ

## 画面

- ホーム（Stories + フィード + 右レール）
- 失敗ブース
- チャレンジ（部署バトル）
- トピック / 人・ツール棚 / 自分
- コンポーザー（失敗ブース投稿テンプレ含む）

## 起動

```bash
cd /workspace/ai-sns-ui
npm install
npm run dev
```

本番ビルド:

```bash
npm run build
npm run preview
```

## スタック

Vite · React · TypeScript · Tailwind CSS v4 · lucide-react

## テーマ

- **ブライト・ユースフル・ハイエナジー**：ページ背景は暖白／パステルクリーム。カードは白＋ソフトシャドウ。アクセント（ライム／ホットピンク／シアン）はライト上のポップとして高コントラストに維持。
- サイドバーは白／ソフトパステル。アクティブナビはライム強調。黒インクのカラムなし。
