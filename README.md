# Pulse — 社内でAIの使い方を共有する

従業員がAIのやり方・事例・失敗・お題を共有する、**社内専用**のインタラクティブ・プロトタイプ。

バックエンドなし（モックデータ + ローカル state）。

## コンセプト

> 社内でAIの使い方を共有する場所

うまくいったやり方を書いて、失敗した話も残して、部署でお題に参加する。誰が今どのツールを使っているかも見られます。

## 機能

1. **失敗ブース** — 匿名の失敗談。時間切れで消える。たくさん「あるある」がつくと、少し残ることがあります。通常フィードとは別画面。
2. **試した人** — 投稿のプロンプトをコピーして試す → 結果を一行書くと、投稿の下に並ぶ。
3. **部署対抗チャレンジ** — 週次の部署スコア（営業 vs エンジニアなど）。投稿・「試した」でポイント加算、応援も可。
4. **今日のTips** — 画面上部の短いメモ。24時間で消えます。タップで大きく表示。
5. **いま触ってる** — Cursor / Claude / ChatGPT など、誰がどのツールを使っているか。
6. **社内ツール** — ライセンス済みツール一覧 + 「この人に聞ける」。
7. **フィード** — フィルター: 学び / 事例 / 質問 / 失敗 / チャレンジ

## 画面

- ホーム（Tips + フィード + 右レール）
- 失敗ブース
- チャレンジ（部署の順位）
- トピック / 人・ツール / 自分
- 投稿フォーム（失敗ブース用あり）

## 起動

```bash
cd /workspace/ai-sns-ui
npm install
npm run dev
```

本番ビルド:

```bash
npm run build
npm run preview
```

## スタック

Vite · React · TypeScript · Tailwind CSS v4 · lucide-react

## テーマ

- Threads 寄りのテキストファースト。背景は `#fafafa`、フィード列は白、罫線はヘアライン。
- アクセントは Instagram ブルー（`#0095F6`）1色。Stories リングだけ IG グラデ。
- ナビは黒のアクティブ、投稿ボタンは黒のピル。ライム／ピンク／シアンの同時使い、ガラスカード、ヒーローバナーはなし。
